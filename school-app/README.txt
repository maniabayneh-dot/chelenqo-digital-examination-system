# CHELENQO School App

This is a separate mobile/PWA version added under /school-app/ so the existing
CHELENQO website files are not replaced.

Live path after deployment:
https://maniabayneh-dot.github.io/chelenqo-digital-examination-system/school-app/

It uses the existing Supabase project and publishable browser key.
Do not put a Supabase service-role/secret key in browser code.

Current features:
- Student login using the existing Student ID email convention
- Teacher login
- Administrator login
- CHELENQO school/role verification
- Mobile/PWA manifest

The examination module will be added after authentication is verified.
